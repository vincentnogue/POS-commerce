## 🎯 Enterprise Features

### Core Modules (18 Native)
- **Dashboard** - Real-time KPIs, multi-store overview
- **POS** - Offline-first, touch-optimized, barcode scanning
- **Inventory** - Real-time stock, multi-store transfers

## 🏗️ Tech Stack

```
Frontend:     React 18 + TypeScript + Vite + Tailwind CSS
Backend:      Supabase (PostgreSQL + Edge Functions/Deno)
Realtime:     WebSockets
Payments:     Stripe, PayPal, Flutterwave, Paystack, M-Pesa, Orange Money
Hosting:      Vercel (Frontend) + Supabase (Backend)
```

