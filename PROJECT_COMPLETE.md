## 🚀 TO CONNECT PAYUNIT.NET

### Step 1: Create Account
```
Visit: https://www.payunit.net
Sign up as merchant
Complete verification
```

### Step 2: Get Credentials
```
Login to dashboard
Settings → API
Copy API Key
Copy Merchant ID
```

### Step 3: Connect in POS Flow
```
Marketplace → PayUnit.net
Click "Connect"
Paste API Key
Paste Merchant ID
Click "Test Connection"
Enable integration
```

### Step 4: Start Accepting Payments
```
POS Module → Process Payment
Select PayUnit.net
Enter amount
Customer completes payment
Auto-sync to accounting
```
