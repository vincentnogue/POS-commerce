## 🚀 GETTING STARTED

### 1. **Sign Up** (New Customer)
- Go to https://pos.liafrik.com/signup
- Enter email
- Set password
- Confirm email
- Complete onboarding

### 2. **Login** (Existing Account)
- Go to https://pos.liafrik.com/login
- Enter email & password
- Dashboard loads automatically

### 3. **Configure Settings**
- Click Settings in sidebar
- Set country, timezone, currency
- Currency auto-sets based on country
- All settings auto-save

### 4. **Connect Integrations**
- Go to Marketplace
- Choose payment processor
- Enter API credentials
- Test connection
- Enable for payments

### 5. **Start Accepting Payments**
- Use checkout widget
- Select payment method
- Automatically uses user's currency
- Payments processed in real-time
